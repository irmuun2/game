# Хичээлийн сан — газар зүй

Газар зүйн багш нарт зориулсан хичээлийн сан. Хичээл бүрт гурван хэсэг байна:
- **Дэлгэцийн хичээл** — ангид дэлгэцээр харуулна (HTML хичээлийг сайт дотроо нээнэ)
- **Тараах материал** — дасгал, ажлын хуудас (Word, PDF, зураг)
- **Хичээлийн төлөвлөгөө** — арга зүй бүрээр тусдаа хувилбар (арга зүйн нэрийг багш өөрөө өгнө)

Мөн **Миний хуваарь** (дадлагын хичээлээ огноо, цагаар товлох), **Админ** (багш зөвшөөрөх) хэсэгтэй.

- Нэвтрэлт: имэйлд ирэх 6 оронтой код. Анх нэвтэрсэн багш «хүлээгдэж буй» болж, эзэмшигч зөвшөөрнө.
- Өгөгдөл: «Дэлхийн гадарга» тоглоомын **ижил Supabase төсөл** (lib_ гэсэн хүснэгтүүд, `lib-files` хадгалах сан). Шинэ Supabase төсөл үүсгэхгүй.
- Анги → бүлэг → сэдэв нь `src/catalog.js`-д (7–10-р анги сурах бичгээр). 11-р анги болон нэмэлт хичээлийг админ сайт дээрээс нэмнэ.

## Газрын зураг
Сэдэв бүрийн «Газрын зураг» хэсгийн агуулга `src/maps.js`-д (түлхүүр нь `<анги>/<код>`). Харагч нь `src/mapview.js` (Leaflet, интернэт хэрэгтэй). Суурь зураг: сансрын (Esri), физик (Esri), байрзүйн (OpenTopoMap), засаг захиргааны (OpenStreetMap HOT: аймаг, сумын хил). «🌐 3D загвар» нь MapLibre GL 5.6 (cdnjs) ба AWS Terrain Tiles өндрийн өгөгдлөөр (түлхүүргүй) сонгосон суурийг 3 хэмжээсээр харуулна. Шинэ газрын зураг нэмэхдээ maps.js-д мөр нэмж, GitHub-д оруулна.

## Байршуулах (нэг удаа)
1. **Supabase → SQL Editor → New query** → `supabase/schema.sql`-ийг бүтнээр нь буулгаад **Run**.
   Дараа нь файлын төгсгөлд байгаа «Эзэмшигч» SQL-ийг өөрийн имэйлээр ажиллуулна.
2. **GitHub** дээр шинэ репо үүсгэнэ (жишээ нь `hicheeliin-san`) → энэ хавтсын `src`, `scripts`, `supabase` хавтас ба `package.json`, `vercel.json`, `config.public.json`, `README.md`, `CHANGELOG.md`, `.gitignore`-ийг оруулна.
3. **Vercel → Add New → Project** → репогоо Import → Deploy. (Тохиргоог `vercel.json` өөрөө заана.)
4. **Supabase → Authentication → URL Configuration → Redirect URLs** хэсэгт Vercel-ийн шинэ хаягийг нэмнэ (Site URL-ийг өөрчлөхгүй — тоглоомынх хэвээр).

## Хичээл нэмэх
**Багшийн хавтсан дахь материалыг нэг дор:** `node scripts/make-import.js` → `import/` хавтас (интерактив хичээл, төлөвлөгөө, тараах материал) бэлэн болно. Сайт дээр **Админ → Материал олноор оруулах** → `import` хавтсыг сонгоод «Оруулах». Хичээлүүд автоматаар үүсч, файл бүр зөв анги, сэдэв, хэсэгт орно. Шинэ материал нэмэх бол `scripts/make-import.js`-ийн жагсаалтад мөр нэмнэ. `import/` хавтас GitHub-д орохгүй.

**Нүүр зураг:** `node scripts/make-import.js`-ийн дараа `node scripts/make-thumbs.js` → сэдэв бүрийн дэлгэцийн хичээлийн нүүр (480×270 JPEG) `src/thumbs/`-д, жагсаалт нь `src/thumbs.js`-д үүснэ (Windows, Edge хэрэгтэй). Шинэ хичээл нэмсний дараа дахин ажиллуулж, `src/thumbs/` хавтас, `src/thumbs.js`-ийг GitHub-д оруулна.

**Нэг нэгээр:** Хичээлүүд цэснээс анги, сэдвээ сонгоод хичээлийн хуудасны «Файл нэмэх» хэсгээс оруулна (файл бүр 50 МБ хүртэл, нийт 1 ГБ үнэгүй).
Сурах бичигт байхгүй хичээлийг бүлгийн доорх «+ Нэмэлт хичээл»-ээр нэмнэ.

## Компьютер дээрээ турших
```bash
npm run build
npm run dev
```
http://localhost:3001 — Supabase-д нэвтэрч ажиллана (schema.sql ажиллуулсан байх ёстой).

## Демо (Supabase-гүйгээр харах)
```bash
npm run demo
```
http://localhost:3002/?as=owner — эзэмшигчээр. `?as=teacher` (энгийн багш), `?as=pending` (зөвшөөрөл хүлээж буй), `?as=out` (нэвтрээгүй, код 123456). Өгөгдөл зөвхөн тухайн хөтөчид хадгалагдана.

## Хувилбар
`package.json`-ийн version (0.1.0 → «V.0.1») сайтын доод хэсэгт харагдана. Шинэчлэл бүрт дунд тоог нэмж, `CHANGELOG.md`-д бичнэ.
